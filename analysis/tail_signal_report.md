# 尾数预测信号分析报告

日期：2026-09-09
数据：2366 期（2020-03-18 ~ 2026-09-08），`records` 表全量
脚本：`analysis/tail_signal_analysis.py`（可重复运行）

## 一、现有预测逻辑

`/api/tail-analysis` 把抽签数字按尾数分两组 `0-4尾` vs `5-9尾`，预测规则：

- 算每组「当前连续天数」和「历史最长连续天数」
- `ratio = 当前连续 / 历史最长`
  - ratio ≥ 0.8 → 警告反转
  - ratio ≥ 0.5 → 可能延续
  - 否则 → 继续看好
- 选「当前连续天数更大」的组当主预测

核心假设：**连续越长越容易反转（均值回归）**。

## 二、数据真相

| 检验 | 结果 | 结论 |
|------|------|------|
| 两分类占比 | 0-4尾 48.0% / 5-9尾 52.0% | 接近 50/50 |
| 0-4尾连续k天后延续 | 36%~51%（k=1~8） | 无反转规律 |
| 5-9尾连续k天后延续 | 50%~58% | 稳定 50%，无反转 |
| 尾数遗漏回归 | 遗漏5期→9.8%，20期→9.2%（基线10%） | 越冷越不回归 |
| 近30期热尾延续 | 30.3%（基线30%） | 无信号 |
| 号码遗漏回归 | 遗漏178期→2.55%（基线2.04%） | 唯一微弱正信号 |
| 单双 | 51.6% / 48.4% | 接近 50/50 |

## 三、策略回测结果

| 策略 | 命中率 | 说明 |
|------|--------|------|
| 始终猜 5-9尾 | 52.05% | 等于 5-9 历史占比 |
| 延续策略（猜上期同组） | 51.21% | 略优于基线 |
| 随机基线 | 50.0% | — |
| 始终猜 0-4尾 | 47.95% | 等于 0-4 历史占比 |
| 反转策略（猜上期反组） | 48.79% | **现有预测的核心假设，最差** |

关键发现：现有预测依赖的「反转」假设，历史命中率只有 48.79%，是所有策略里最差的；「延续」反而略好（51.21%）。

## 四、实证概率 vs 主观阈值（2026-09-08 实盘例）

当前 0-4尾连续 6 天：
- 主观阈值预测：「仍可能延续」（ratio = 6/9 = 0.67）
- 实证转移概率：**反转 56.7%（17次）> 延续 43.3%（13次）**

两者结论相反，印证主观阈值不可靠。

## 五、增强落地（2026-09-09）

1. **A. 实证概率**：`/api/tail-analysis` 返回 `prediction.empirical`，含当前连续k天后的延续/反转实证概率 + 连续长度历史百分位。前端预测卡片直接展示。
2. **C. 回测框架**：新增 `/api/tail-backtest`，返回 4 种策略历史命中率 + 连续k分档表。前端分析弹窗展示策略对比条 + 可展开的连续N天延续概率表。

## 六、结论与下一步

- 尾数层面（两分类/具体尾数/单双）接近真随机，**没有稳定可赢的预测信号**。
- 现有「反转」预测假设在数据上零支撑，反而是最差策略。
- 唯一略超基线的微弱信号：号码超长遗漏（>150期命中率 2.36%~2.55% vs 随机 2.04%），可在「最长未出号码」模块做微偏冷号标注（方案 D，未做）。
- 若要继续深挖：建议对「具体号码 1-49」的遗漏/频率做更细的样本外分段验证，而非尾数两分类。
